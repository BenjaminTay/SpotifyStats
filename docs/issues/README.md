# SpotifyStats 问题记录

这里是项目的长期问题入口，用来记录“已经提出、正在调查、尚未解决、已解决或确认不是问题”的事项。当前台账见 [`2026-08-27-issue-register.md`](2026-08-27-issue-register.md)。

## 使用规则

- 一个问题只保留一个稳定 ID；后续调查、修复和验收都追加到同一条记录。
- 每条记录至少写明范围、当前状态、证据、下一步和最后核验日期。
- `OPEN` 表示问题仍存在或结论未闭环；`IN_PROGRESS` 表示已经开始修改但尚未完成验收；`PARTIAL` 表示部分完成或仍有明确尾项；`RESOLVED` 表示代码、测试和必要的真实数据/页面证据已经闭环；`NOT_A_BUG` 表示已确认当前行为符合规则。
- 方案文档不等于修复完成；只有在交付报告、测试或真实运行证据确认后，才把问题改为 `RESOLVED`。
- 生产、真实数据库、浏览器和 Git 状态都属于带日期的证据快照，更新台账时必须重新核验。

问题台账不替代当前统计规则。规则仍以 [`../reference/`](../reference/) 为准，计划以 [`../plans/`](../plans/) 为准，已完成工作的证据以 [`../reports/`](../reports/) 为准。
