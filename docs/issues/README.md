## 排序规则与非缺陷行为

播放排行同次数按时长和稳定实体键，Billboard周榜按次数、时长及稳定键；Records对完整候选排序后截断，同值按业务二级键和稳定实体键。规则及具体列表见[统计规则](../reference/playback-stats-rules.md#r391-records-记录板块稳定排序)。不从旧排序提问重新登记已确认的符合规则行为。

## 维护规则

复用稳定ID，新增问题记录现象、复现、范围、判断和证据。实现、本地应用、提交、推送、部署、外部验收、优先级、下一步及最后核验日期只在开发状态总表维护；阶段细节写报告，台账保留问题判断与证据链接。历史路径和复现通过[历史台账](../archive/06-productization-closeout/2026-10-25-issue-register-history.md)承接。

一个问题只保留一个稳定ID；后续调查、修复和验收追加到同一条记录。方案不等于修复完成，状态由总表依据实际证据维护。台账不替代[统计规则](../reference/playback-stats-rules.md)或[当前路线](../README.md#当前计划与历史追溯)。
