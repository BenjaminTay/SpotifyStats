# 全站封面图片优化实施方案

> 问题 ID：`SS-2026-10-03-001`
> 状态：S0–S5 已完成；业务版本 `814ea7cb` 已正式发布，完整本地全栈、生产资产与实际 HTTPS 验收闭环。最后核验 2026-10-03；证据见[交付报告](../../reports/2026-10-03-cover-image-optimization-acceptance.md)。
> 基线：本地 `7b9a1f4e`，生产 `3a4e6310`；用户实际入口 `https://stats.benjaminlei.site`。

## 目标

补齐所有当前有效入口的本地小封面，统一尺寸选择；优化有直接收益证据的首页、档案和详情中大图，保持原图与统计事实。实现、专项验收、完整全栈、提交和生产验收分别登记。

## S0：覆盖和测量基线

- 记录有效组件、URL 来源、各视口显示尺寸、加载优先级、重复/唯一图片及例外。
- 固定页面参数和版本，分别测 Desktop、Compact、Phone、高 DPR；冷/热缓存各三次。
- 图片挂载或明确空态/错误/未准备状态后测量；不能以零图片作为图片验收成功。
- 首屏、完整滚动、图片体积、完成时间分别记录；用户 HTTPS 与服务器 loopback 链路单独归属。
- 六张首页样本原图长边 640px、44.5–126KB；同尺寸 WebP 13.5–33KB，320px 5.1–9.7KB。该测量支持新增固定 320/640 派生图。非方图保留比例，不声明虚假 `srcset` 宽度。

## S1：统一选图

- `coverArtworkUrl(url, 160|320|640|'original')` 是本地音乐封面选择入口。
- 160 保持 `.thumb.webp` 及旧文件路径；320/640 使用 `.320.webp` / `.640.webp`。
- 仅本地数字 ID 的 albums/artists 可转换；query/hash 保留，已派生地址可重新选择尺寸；外部和未知地址保持原样。
- 小图常见 40–64px 使用 160；约 80–160px 使用 320；约 200–350px 大视觉使用 640，完整原图查看保留 original。
- 高 DPR 的首次渲染由 `coverDisplayUrl` 提升必要档位：160 在 DPR > 2 升 320，320 在 DPR > 1.5 升 640；已有列表也共用该选择。非方源图保留比例，原图能力不足时不放大。
- 不生成独立前端数据缓存，不改变页面事实、布局、圆角、占位和点击行为。

## S2：小封面完整覆盖

顺序：播放记录 → 音乐档案双版 → 当前年度 V2 → 首页小图 → 版本列表/设置/兼容跳转。榜单、播放排行、最近播放、音乐搜索和详情成员列表回归。

当前年度章节通过 V2 公共组件覆盖 Desktop/Phone。旧 `pages/yearly-review`、歌词/发行档案/生涯等非当前消费入口登记为非有效入口，不恢复这些功能。社区帖子若使用本地音乐封面，按实际展示尺寸转换；外部头像、播客/节目图和外部帖子图片保留原来源并单列。

## S3：持久多尺寸派生图

- 固定白名单 160/320/640，Pillow 不放大源图、保留 EXIF 方向和原图，原子发布。
- GET 仅读取现有文件，缺失/过期短缓存回退原图，不同步压缩。
- 新下载生成各尺寸；错误不影响原图发布。
- 补建支持尺寸选择、有界批次、有效文件跳过、失败计数和非零退出码；不改数据库。
- 生产补建观察 CPU、RSS、磁盘，固定源文件前后数量/体积摘要；旧地址长期兼容。

## S4：验收

1. URL 选择、query/hash、外部地址、切换、错误恢复；变体尺寸/格式/无放大/竞态、缺失与过期回退、缓存和 304、公开只读白名单。
2. 前后端回归、构建、文档审计、hooks、三部署模式；默认完整全栈使用隔离数据库副本，局部成功只标 Partial。
3. 所有有效区域浏览器图片消费清单；首屏和逐屏滚动、分页/筛选、实际链接、图片清晰度、占位及懒加载。
4. 固定数据/参数的冷热三次中位数；图片传输体积和页面加载耗时分别报告。小图集合相对原图体积降低目标 70%，例外说明来源与实际体积。

## S5：发布及收口

- 完整阶段再提交；仅暂存本任务文件/文档 hunk，保留工作区既有改动。
- 固定 SHA 经现有 Actions 发布，Online Backup、三模式、健康和联合回滚不变。
- 补建必要资产，确认实际输出格式和尺寸、运行 SHA、缓存条件请求；用户 HTTPS 和服务器入口分别验收。
- 更新开发状态、问题台账、规则和报告；完成方案归档并更新文档地图。

## 完成标准

所有有效本地小图按统一规则选图；中大图有尺寸/清晰度依据；缺失图有稳定回退；服务器有必要派生资产；功能、资源、传输与线上证据齐全；原始数据和外部入口保持既有行为。
