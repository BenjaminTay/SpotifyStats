# 发行周期分析 — 设计规格

## 概述

在 Billboard 周榜中新增「发行周期」Tab，以专辑/单曲发行日为锚点，分析艺人榜单表现与发行周期的关联。核心能力：艺人发行时间线总览、单张专辑发行前后深度分析、多发行周期叠加对比。

## 架构

### 文件组织

在 `app/pages/billboard/` 下新增 `release_cycle/` 子包：

```
app/pages/billboard/release_cycle/
├── __init__.py          # 主路由：艺人选择 + 三个子视图切换
├── shared.py            # 数据加载 + 指标计算
├── artist_view.py       # 视图①：艺人总览
├── album_view.py        # 视图②：专辑下钻
└── compare_view.py      # 视图③：对比视图
```

### 入口

- `08_billboard.py` 新增第 12 个 Tab「发行周期」，委派至 `release_cycle/__init__.py`
- 不修改现有 11 个 Tab 的任何文件，零回归风险
- 艺人选择用搜索式下拉框，不依赖其他 Tab 的交互

### 子视图导航

三个子视图在 Tab 内部通过 `st.session_state` 切换：

```
发行周期 Tab
├── 艺人选择器（始终在顶部）
├── [视图①] 艺人总览（默认）
│   ├── 点击专辑卡片 → 进入视图②
│   └── 勾选多张 → 进入视图③
├── [视图②] 专辑下钻
│   ├── ← 返回总览
│   └── 添加到对比队列
└── [视图③] 对比视图
    └── ← 返回总览
```

## 导航流

```
st.session_state 键值：
  rc_view: "artist" | "album" | "compare"
  rc_selected_artist: str
  rc_selected_album: str
  rc_compare_queue: list[dict]  # [{artist, album}, ...]
```

- 艺人选择器变更 → 重置视图为 "artist"，清空专辑选择
- 点击专辑卡片 → 设置 rc_view="album", rc_selected_album
- 勾选卡片 + 点击对比 → 设置 rc_view="compare"
- 「← 返回」→ 设置 rc_view="artist"
- 面包屑反映当前层级

## 数据层

### 新数据查询（shared.py）

所有查询通过 `st.cache_data` 缓存。

**1. 获取艺人所有发行**

```sql
-- 通过 artists → albums → track_albums → tracks → spotify_track_meta → spotify_album_meta
SELECT DISTINCT
    sam.album_name,
    sam.album_type,
    sam.release_date,
    sam.spotify_album_id
FROM artists a
JOIN albums al ON al.artist_id = a.artist_id
JOIN track_albums ta ON ta.album_id = al.album_id
JOIN tracks t ON t.track_id = ta.track_id
JOIN spotify_track_meta stm ON REPLACE(t.spotify_track_uri, 'spotify:track:', '') = stm.spotify_track_id
JOIN spotify_album_meta sam ON stm.spotify_album_id = sam.spotify_album_id
WHERE a.artist_name = ?
  AND sam.album_type IN ('album', 'single')
  AND sam.release_date IS NOT NULL
ORDER BY sam.release_date
```

排除 `compilation` 类型（合辑与艺人创作周期无关）。

**2. 艺人每周表现**

基于 `compute_artist_weekly_rankings()` 但仅过滤目标艺人，返回完整历史（不限 Top N）：`billboard_week, play_count, rank`。

**3. 专辑发行周期数据**

以发行日为锚点，拉取前后各 N 周（默认前 12 周 + 后 24 周）：

- 该艺人的每周排名和播放量
- 该专辑的每周排名和播放量
- 专辑中所有歌曲的每周排名（用于入榜矩阵）
- 所有相关歌曲的所属专辑信息（用于回榜检测）

**4. 老歌回榜检测**

```
输入：目标专辑发行日、目标艺人所有歌曲的排名历史
输出：标记为回榜的歌曲列表

规则：
  FOR 发行后 +1..+N周内入榜的每首歌：
    IF 歌曲所属专辑的发行日 < 目标专辑发行日  (来自更早专辑)
    AND 歌曲在 [发行前4周, 发行周) 期间始终未入榜  (断档后重新入榜)
    THEN → 回榜
```

### 指标计算

| 指标 | 计算方式 | 适用范围 |
|------|----------|----------|
| 首单空降排名 | 先行单曲发行周的排名 | 有先行单曲的专辑 |
| 专辑空降排名 | 专辑发行周的专辑榜排名 | 所有专辑 |
| 双冠 | 发行周单曲 #1 AND 专辑 #1 | 所有专辑 |
| Peak 排名 | 周期内最高排名 | 专辑、单曲 |
| 入榜到 Peak 周数 | Peak 周偏移 - 首次入榜周偏移 | 专辑、单曲 |
| 在榜周数 | 排名非空的周数 | 专辑、单曲 |
| 发行冲击力 | `(发行后峰值播放量 - 发行前4周均值) / 发行前4周均值 × 100%` | 专辑 |
| 衰减半衰期 | 从 Peak 到播放量 ≤ Peak×0.5 的周数，24周内未衰减则标记 ">24周" | 专辑 |
| 同时在榜歌曲数 | 单周内专辑中入榜歌曲数的最大值 | 专辑 |
| 回榜歌曲数 | 发行后重新入榜的旧专辑歌曲数 | 专辑 |

艺人级别汇总指标：发行总数（album+single）、空冠次数、双冠次数、最大冲击力、总回榜歌曲数。

## UI 视图

### 全局元素

- **艺人选择器**：搜索式下拉框，支持中文/英文，始终在页面顶部
- **面包屑**：发行周期 > Olivia Rodrigo > GUTS（专辑下钻时显示）
- **样式**：复用现有 `app/styles.py` 的 Vinyl Archive 主题和 Plotly 模板

### 视图① — 艺人总览

**KPI 卡片行**：
- 发行总数（X 张专辑 / Y 首单曲）
- 空冠次数（debut #1）
- 最大发行冲击力（+XXX%）
- 回榜歌曲总数

**艺人周榜排名折线图**：
- X 轴：时间（billboard_week）
- Y 轴：排名（倒序，#1 在顶部）
- 在曲线上标记所有发行事件点（竖虚线 + 标签）
- 悬停显示发行名称和当时排名
- 使用 Plotly，和现有 Billboard 图表风格一致

**专辑发行卡片流**：
- 横向排列（wrap），每张专辑一张卡片
- 卡片内容：专辑名、发行日期、Peak、在榜周数、冲击力
- 每张卡片有「查看详情」按钮 → 进入视图②
- 每张卡片有勾选框，勾选 ≥2 张后显示「对比选中」按钮 → 进入视图③

### 视图② — 专辑下钻

**顶部导航**：「← 返回 Olivia Rodrigo 总览」按钮 + 「添加到对比队列」按钮

**专辑信息行**：专辑名 · 类型 · 发行日期 · 先行单曲（如有）

**KPI 卡片行**：
- 首单信息（名称 + 发行日，如有）
- 空降排名（专辑榜 + 单曲榜，双冠特别标注）
- 在榜周数 / Peak
- 衰减半衰期

**发行前后排名曲线**（核心图表）：
- X 轴：相对发行日的周偏移（0 = 发行周）
- Y 轴：排名（倒序）
- 竖虚线标记发行周（offset=0）和首单发行周（如有）
- 多条线：艺人排名、专辑排名、专辑中入榜的各首单曲排名
- 双 Y 轴可选：右轴展示总播放量柱状图
- 图例可点击切换显示/隐藏

**专辑歌曲入榜矩阵**（热力图）：
- 行 = 专辑中入榜的歌曲（按首次入榜时间排序）
- 列 = 周偏移（仅显示歌曲实际在榜的范围）
- 色阶 = 排名（#1 最深色，越往后越浅，灰色=未入榜）
- 使用 Plotly heatmap 或 st.dataframe 条件格式

**老歌回榜表**：
- 表格列：歌曲名、来源专辑、回归周偏移、在榜周数
- 无回榜时显示「发行未带动老歌回榜」
- 可展开看详情

### 视图③ — 对比视图

**顶部**：「← 返回」按钮 + 「清空队列」按钮 + 队列数量显示

**排名对比曲线**：
- X 轴：相对发行日的周偏移（对齐发行周为 0）
- Y 轴：排名（倒序）
- 每条曲线 = 一个发行周期，不同颜色
- 图例显示「专辑名 (发行年)」

**播放量对比曲线**：
- 同上，Y 轴改为播放量

**指标对比表**：
- 行 = 指标，列 = 各发行周期
- 指标列表：空降排名、Peak、在榜周数、冲击力、半衰期、同时在榜歌曲数、回榜歌曲数
- 每行最优值高亮

## 技术要点

- 所有数据查询通过 `@st.cache_data(ttl=3600)` 缓存
- 复用 `load_billboard_raw()` 获取原始数据，在其基础上做艺人/专辑过滤
- 复用 `compute_artist_weekly_rankings()` / `compute_album_weekly_rankings()` / `compute_weekly_rankings()`
- 复用 `_load_album_metadata()` 获取 release_date
- 样式复用 `app/styles.py` 的 `page_header()`, `kpi_row()`, `PLOTLY_TEMPLATE`, `COLORS`
- 三个视图混合在同一 Tab 内通过 `st.session_state.rc_view` 切换
- 面包屑和返回按钮确保用户不迷路
- 「添加到对比队列」存储 `[{artist_name, album_name, release_date}]`，限制最多 5 条
- 对比队列跨视图保持（session_state），切回总览仍有效
