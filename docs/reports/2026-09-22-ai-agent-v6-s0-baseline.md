## 1. 固定任务集

- 历史集：冻结时沿用历史记录中的 33 个 live full 场景；最终执行前核对现行 runner，确认它已扩展为 39 个单轮场景和 3 个多轮场景（42 cases、45 turns），因此按当前集合全量执行，不删题、不降低断言。
- 新自由问法：`backend/tests/fixtures/ai_agent_v6_freeform_questions.json`，共 24 个场景；自然改写、指代、多轮、歧义、组合维度、运行中转向各 4 个。
- 稳定性集：固定取 `V6-NAT-01/02`、`V6-REF-01/03`、`V6-MUL-01/04`、`V6-AMB-01/03`、`V6-COM-02/03`、`V6-STR-01/04`，每题累计运行 3 次。
- 年报：一个完整年度 3 组冷/热配对；另测一个部分年度和一个无数据年度。

## 2. 数据与执行隔离

真实评测只允许读取 SQLite Online Backup 创建的副本。主库、报告缓存、任务库、上下文 sidecar、封面目录和临时产物必须显式指向隔离目录。正式 `data/`、现有缓存和用户服务不清理、不切换、不写入。性能样本运行前后检查主机锁与外部测试 Worker；发现竞争的窗口保留原始数据但不进入可比结论。

## 3. 固定预算

- 场景执行上限：最终按现行 42 个历史场景加 24 个自由问法各一次，再对 12 个稳定性场景追加两次；失败只重跑受影响场景并保留原始失败文件。
- 报告正常样本：3 冷 + 3 热；边界年份各 1 次。
- 单 Chat 使用当前动态上限：最多 7 步、12 次工具调用、150 秒；简单/标准问题使用更低动态预算。
- 失败只重跑受影响场景；原始失败样本保留。Provider 无价格合同，因此只报告请求数与 token，不推算金额。

## 4. 测量定义与门禁

- API ACK：创建、steer、cancel 从请求发出至收到持久化回执，P95 不超过 1 秒。
- UI 反馈：持久事件可读至页面投影更新，受控本地网络 P95 不超过 1 秒。
- 历史问答：现行 runner 42/42 必需断言通过；Turn P95 不超过 60 秒，Tool P95 不超过 45 秒。
- 新问法：24/24 达到预定义的正确回答、必要澄清或准确能力边界；拒答不能替代可执行答案。
- 报告：每个冷样本不超过 240 秒、热样本不超过 180 秒；每份最多 2 章确定性补齐；首个审核章节早于完整发布。
- 可比性能与用量：匹配样本中位数不高于 S0 的 115%；两版都先满足质量门禁。
- 恢复复用：已提交成功工具结果和版本兼容章节恢复后新增执行数为 0；累计步骤、调用、重试和 token 不重置。

## 5. 原始证据格式

每个样本保存：case ID、代码版本、数据副本标识、模型及参数、开始/结束时间、模型/工具调用数、prompt/completion/reasoning/cache token（Provider 提供多少记录多少）、重试、fallback、最终状态、断言结果与人工阅读结论。报告样本另存上下文命中、各章提交时间、总审和发布时间。S0 与最终候选使用同一字段和统计脚本；不以重抽样替换失败值。
