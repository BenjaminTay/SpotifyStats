## 报告阅读规则

- 先看报告开头的状态、范围和证据日期。
- 真实数据库数量、性能数字和测试数量都是快照，不自动代表当前状态。
- 发现规则冲突时，优先检查当前代码、测试和 `docs/reference/`。
- 报告中引用的旧路径只代表当时的目录，不应复制到新文档。
