## 维护规则

同一天同一问题链优先追加主题文档，阶段通过章节分开；不同版本的事实、失败与验收范围分别说明。只有独立问题、跨日完整交付或独立复盘才新建报告，避免每个候选、测试轮和提交检查都新增文件。

历史实施计划见[归档索引](../archive/README.md)，完整变更历史见[月度记录](../archive/changelog/README.md)。本次合并清单和验收见[整理报告](2026-10-25-documentation-cleanup-delivery.md#第三轮同日同题合并)。
