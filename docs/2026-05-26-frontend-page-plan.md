# 新版前端页面架构规划

> 本文档定义 React 前端的页面架构、导航结构和每个页面的功能清单。
> 对照文档：`docs/2026-05-25-streamlit-feature-inventory.md`（旧版 Streamlit 完整功能清单）。

## 设计原则

- **按用户意图组织**：以用户想回答的问题为核心，而非数据表结构
- **页面数量适中**：6 个顶级页面
- **每个页面有明确的核心问题**：打开这个页面，用户想回答什么
- **内容密度合理**：深度页面用 Tab 组织

## 导航结构

```
总览  |  播放分析  |  Billboard  |  年度回顾  |  账号  |  设置
 /    | /analytics | /billboard  |  /yearly   | /account | /settings
```

## 页面 6：设置 `/settings`

**核心问题**：如何定制我的数据分析体验？

| # | 区域 | 内容 |
|---|------|------|
| 1 | 数据过滤 | `min_ms` 滑块（最短播放时长）、`music_only` 开关（仅音乐）、`merge_enabled` 开关（合并连续播放） |

| 4 | 数据导入 | 串流数据导入（含进度反馈）+ 账号数据导入 |
